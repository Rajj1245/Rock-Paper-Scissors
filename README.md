# **Rock Paper Scissors Game**

## **Description**
This is a simple **Rock-Paper-Scissors** game made using **JavaScript**.  
The game runs in the **browser console** and lets the user play against the computer.

## **How to Run**
- Open `index.html` in your browser  
- Right-click on the page and click **Inspect**  
- Go to the **Console** tab  
- Wait a few seconds and follow the prompts  

## **How to Play**
- Enter:
  - `1` for **Rock**  
  - `2` for **Paper**  
  - `3` for **Scissors**  
- The computer will randomly choose its move  
- The game runs for **5 rounds**  
- Final score is shown in the console
